# Start here

This folder is the complete, portable website for Dongming Zhao. It is configured to preview at **projects.mindx.us/dongming-zhao/** and can later move to another domain without editing page files.

- The live website is what visitors see.
- Pages CMS is Dongming's visual editor for practice details and articles.
- GitHub stores the website and automatically publishes approved changes.

## Routine tasks

Use Pages CMS to update the public email or booking link, create an article, save a draft, publish an article, or upload an article image. A saved change normally appears after GitHub finishes publishing, usually within a few minutes.

Ask the technical administrator for help with design, page structure, menus, fees/policy copy, deployment failures, the domain, or DNS. Never upload client information, intake forms, private notes, passwords, or protected health information.

The original HTML routes are now clean folders: `/about/`, `/individual-therapy/`, `/couples-therapy/`, `/faq/`, `/contact/`, and `/zh/`.
