# Start here

This repository contains Dongming Zhao’s website. The original visual design, colors, page structure, photographs, and supplied copy are preserved.

- **Pages CMS** is where Dongming edits English and Chinese articles.
- **GitHub** stores the website and the edit history.
- **Cloudflare Pages** builds and publishes the site whenever an approved change reaches `main`.

Routine article publishing does not require editing Astro, CSS, deployment settings, or DNS.

Never upload client information, intake responses, clinical records, passwords, or private documents to Pages CMS or GitHub.
