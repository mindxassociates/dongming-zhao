# Pages CMS editor guide

1. Sign in at `pagescms.org` using the invited account.
2. Open Dongming Zhao's website project.
3. Use **Practice settings** for the public email, booking link, service area, languages, or button text. Save when finished.
4. Use **Articles** to create or edit a resource. Enter a clear title, short description, publication date, and article text.
5. Leave **Keep private as draft** on while writing. Turn it off only when the article is ready for the public.
6. For an image, upload it in the image field and write a brief, accurate image description.
7. Save. Publishing usually takes a few minutes. Visit the public page in a private browser window to verify it.

Saving a draft stores it but does not show it publicly. Saving a non-draft article publishes it after the website rebuild completes.

Never upload client information, forms with responses, private notes, passwords, insurance documents, or other confidential material. Use Sessions Health for client communication and clinical information.
